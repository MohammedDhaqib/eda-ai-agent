## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately using GitHub's Private Vulnerability Reporting feature.

Please do not disclose vulnerabilities through public GitHub issues.

Include:
- Description of the vulnerability.
- Affected component or file.
- Steps to reproduce.
- Potential security impact.

## Response Process

Reports will be reviewed as soon as reasonably possible. An initial response is generally expected within seven days. Remediation timelines depend on severity and complexity.

## Security Considerations

- Never commit API keys, passwords, access tokens, or private credentials.
- Do not upload confidential datasets or personally identifiable information.
- Keep dependencies updated and review security advisories.
- Treat externally supplied datasets and model files as untrusted input.
- Do not expose local databases or development services directly to untrusted networks.

## Scope and Limitations

This project is provided for educational, demonstration, and portfolio purposes.

Although reasonable security practices are followed, the project has not undergone a formal independent security audit. Users should evaluate the security of the application and its dependencies before using it with sensitive or production data.
